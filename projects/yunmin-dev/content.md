## 개요

친구들이 각자 도메인을 사서 개인 사이트를 만드는 걸 보고 저도 하나 만들었어요. **yunmin.dev**는 자유롭게 이것저것 개발해 보는 메인 공간이고, 게임은 `game.yunmin.dev`, CV는 `portfolio.yunmin.dev`로 나눌 계획이에요.

## 디자인

평소에 클라이밍을 좋아해서 사이트 전체를 **암장 벽**처럼 꾸몄어요.

- 아이보리 배경에 깔린 점들은 벽의 볼트 구멍(T-너트)이에요.
- 섹션 번호는 루트 시작 지점에 붙이는 색 테이프 모양이에요.
- 메인의 벽에서는 같은 색 홀드가 하나의 루트예요. 한 루트를 다 누르면 완등!

## 홀드는 전부 코드로

홀드 이미지는 한 장도 없어요. 시드 값을 넣으면 매번 같은 모양이 나오는 작은 생성기를 만들었어요.

1. 타원 둘레에 점을 몇 개 찍고, 반지름을 조금씩 흔들어요.
2. 점들을 부드러운 곡선(Catmull-Rom → 베지어)으로 이어요.
3. 그림자, 하이라이트, 손잡이 질감, 볼트 구멍을 얹어요.

직접 돌려볼 수 있게 [Hold Generator](/lab/holds/)로도 만들어 뒀어요.

## 구조

빌드 도구 없이 HTML, CSS, JS만 썼어요. 화면에 나오는 글은 `data.js` 한 파일에 모아 두고, 각 페이지가 그걸 읽어서 그려요. Cloudflare Workers에 정적 파일로 배포해요.
