## 개요

고려대학교 정보대학 **Inthon 2026 데이터톤 트랙**에 3인 팀 **Medoid Trio**(Julia Irsalina, 김재형, 홍윤민)로 참가했어요. 작년 Inthon에 이어 두 번째 Inthon이에요.

## 문제 정의

**Multimodal Reasoning for Image Sequences**: 연속된 이미지 시퀀스를 가장 잘 설명하는 문장을 5개 선지 중에서 찾는 문제예요.

- 예: "소파 앞에 서서 셔츠 단추를 **잠그는**" 장면인지, "**푸는**" 장면인지, "잠근 뒤 소파에 **앉는**" 장면인지 구분해야 해요.
- 선지 5개의 순위를 매겨 내고, 정답이 1등이면 1점, 2등 0.5, 3등 0.25, 4등 0.125, 그 아래는 0점이에요.
- **Train**: 영상 벤치마크(PerceptionTest)에서 뽑은 4,170개 에피소드. 이미지 시퀀스와 **정답 문장 하나만** 있어요.
- **Test**: 다른 벤치마크에서 뽑은 1,910개 에피소드(public 30% / private 70%). 정답 1개와 오답 4개가 있어요.

### 규칙

- 사전학습 모델은 DINOv2, all-mpnet-base-v2, SigLIP, SmolVLM-256M만 쓸 수 있어요.
- 전체 테스트 추론은 15분 안에, T4 GPU 한 장에서 재현 가능해야 해요.
- 외부 생성형 AI로 데이터를 만들거나, teacher 모델로 증류하는 건 금지예요.

## 접근 방법

### 1. 오답 만들기 (텍스트 증강)

Train에는 정답만 있어서, 학습하려면 오답을 직접 만들어야 했어요.

- **L1** 한 단어 바꾸기 (반대 동사, 색·속성, 물체 바꾸기), **L2** 문장 구조 바꾸기 (순서 뒤집기, 동작 바꾸기·추가), **L3** 로컬 LLM으로 다시 쓰기, **L4** 다른 에피소드의 문장
- spaCy와 WordNet으로 규칙 기반 오답을, T4에서 돌아가는 오픈소스 LLM으로 다양한 오답을 만들었어요.
- 단어만 바꾼 오답은 문장만 보고도 83%가 걸러질 만큼 어색해서, SmolVLM으로 부자연스러운 문장을 거르는 단계를 넣었어요.

### 2. 이미지 시퀀스 모델

SigLIP 프레임 특징에 Temporal Transformer를 얹은 모델, 문장을 쪼개 프레임과 맞추는 SeqAlign, Global + Local SigLIP을 시도했어요. 하지만 순서 정보가 거의 학습되지 않아 Public 0.365–0.416에 머물렀어요.

### 3. 텍스트 중심성 (Medoid)

"이미지가 안 읽히면 텍스트를 읽어보자." 오답은 정답을 조금씩 고쳐 만들었을 테니, **다른 선지들과 가장 많이 겹치는 문장**이 정답일 거라는 가설이에요.

- **Word Medoid**: 공통 단어가 가장 많은 문장
- **Meaning Medoid**: 문장 임베딩의 코사인 유사도로 가장 중심에 있는 문장
- 둘을 합치고 3–5 gram 유사도로 긴 흐름도 봤어요.

### 4. Zero-shot VLM + 앙상블 + 파인튜닝

SmolVLM-256M을 학습 없이 써서 "이 영상을 보고 이 문장을 만들 확률"로 순위를 매겼어요. 텍스트 중심성과 거의 독립적인 신호여서(순위 상관 0.065) z-score로 합쳤고, 마지막에 세 가지 loss로 가볍게 파인튜닝했어요.

- Listwise ranking loss: 정답을 더 높게
- Temporal order contrastive loss: 원래 순서의 프레임을 뒤집거나 섞은 것보다 선호
- Action-direction consistency loss: 영상을 거꾸로 돌리면 동작을 뒤집은 문장을 선호

## 결과

| 방법 | Public |
| --- | --- |
| 이미지 시퀀스 모델 | 0.365 – 0.416 |
| Zero-shot SmolVLM 단독 | 0.519 |
| 텍스트 중심성(medoid) 단독 | 0.564 |
| 두 신호 z-score 앙상블 | 0.590 |
| 앙상블 + 파인튜닝 (최종) | **0.599** |

## 배운 점

> 가장 강한 단서는 이미지가 아니라 **텍스트 중심성**이었어요. 학습 없이 medoid만으로 0.564가 나왔어요.

- 동사 방향, 사건 순서, 왼쪽/오른쪽만 다른 선지는 여전히 못 풀었어요.
- 테스트 분포에 맞는 hard negative를 만들었는지 점검이 부족했어요.
- 고정 가중치 대신 학습하거나 확신도를 반영하는 앙상블로 더 올릴 수 있을 것 같아요.
